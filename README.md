# Tic Tac Toe Reimagined

**In-game title:** Neon Tic-Tac-Toe Ultimate  
**Historical label:** Advanced Tic-Tac-Toe  
**Status:** original browser board and strategy game  
**Play:** https://joenasriani.github.io/tictactoe-advanced/  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

Tic Tac Toe Reimagined expands the familiar game into larger grids with adaptive win conditions, CPU play, local play and an optional online multiplayer mode.

## Lineage

Tic Tac Toe Reimagined, Neon Tic-Tac-Toe Ultimate and Advanced Tic-Tac-Toe refer to the same game lineage.

## Gameplay

The board can expand beyond 3x3 after drawn rounds, with win conditions adapting to the grid size. The interface supports mouse and touch input.

## Technology

HTML, JavaScript, Tailwind CSS and optional Firebase services for online play.

Existing branches and historical files are retained as development history.
