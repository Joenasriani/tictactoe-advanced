Tic Tac Toe Reimagined

This is the information page for the browser game also identified in the source as Neon Tic-Tac-Toe Ultimate.

The game begins on a 3×3 Tic-Tac-Toe board. When a round ends in a draw, the next round expands to a larger square grid and the required line length grows with the board size.

Game modes

  • CPU mode uses Minimax on the 3×3 board and simpler move-selection logic on larger boards.
  • Local mode supports two players on the same device.
  • The source includes Firebase Authentication and Firestore room logic for an online mode. That mode requires Firebase configuration supplied at runtime.

Implementation

The game is implemented in a single index.html file with vanilla JavaScript, Tailwind CSS loaded from CDN, Google Fonts, and Firebase modules loaded from CDN.
